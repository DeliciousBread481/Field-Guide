**Global Blacklists:**
Add an ID to the `fieldguide:blacklisted` tag.

* **Entities:** `data/fieldguide/tags/entity_type/blacklisted.json`
* **Blocks:** `data/fieldguide/tags/block/blacklisted.json`
* **Items:** `data/fieldguide/tags/item/blacklisted.json`

**Per-Category Blacklists:**
Create a tag formatted as `fieldguide:blacklisted/<category_namespace>/<category_path>`.
(e.g., `data/fieldguide/tags/entity_type/blacklisted/fieldguide/monsters.json`)
