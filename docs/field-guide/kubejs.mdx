---
title: KubeJS Integration
---

Field Guide provides KubeJS integration that allows you to interact with player progress and mod systems through scripts.

### The 'FieldGuide' Global
You can access the integration via the global `FieldGuide` object in your server scripts.

#### Methods

| Method | Description |
| :--- | :--- |
| `isUnlocked(player, entryId)` | Returns `true` if the player has unlocked the specified entry. |
| `unlock(player, entryId)` | Unlocks an entry for the player. |
| `unlock(player, entryId, variantId)` | Unlocks a specific variant of an entry for the player. |
| `revoke(player, entryId)` | Revokes an entry from the player's progress. |
| `revokeAll(player)` | Clears all progress for the player. |
| `getProgress(player)` | Returns the `PlayerFieldGuideProgress` object for the player. |
| `getManager()` | Returns the `ServerFieldGuideManager` instance. |
| `getProgressManager()` | Returns the `FieldGuideProgressManager` instance. |

### Examples

#### Unlocking an entry when an item is used
```javascript
ItemEvents.rightClicked('minecraft:stick', event => {
    if (event.player.isCrouching()) {
        FieldGuide.unlock(event.player, 'minecraft:cow')
        event.player.tell('You unlocked the Cow entry!')
    }
})
```

#### Checking if an entry is unlocked
```javascript
PlayerEvents.loggedIn(event => {
    if (FieldGuide.isUnlocked(event.player, 'minecraft:zombie')) {
        event.player.tell('Welcome back, zombie hunter!')
    }
})
```

#### Revoking progress
```javascript
ServerEvents.commandRegistry(event => {
    const { commands: Commands, arguments: Arguments } = event;
    
    event.register(
        Commands.literal('reset_guide')
            .executes(ctx => {
                const player = ctx.source.player;
                if (player) {
                    FieldGuide.revokeAll(player);
                    player.tell('Your Field Guide has been reset.');
                }
                return 1;
            })
    );
});
```

### API Reference

For advanced users, `FieldGuide.getManager()` and `FieldGuide.getProgress(player)` return the actual Java objects used by the mod. Below are some of the most useful methods available on these objects.

#### PlayerFieldGuideProgress
Accessible via `FieldGuide.getProgress(player)`.

| Method | Description |
| :--- | :--- |
| `getUnlockedEntries()` | Returns a `Set<String>` of all entry IDs the player has unlocked. |
| `markSeen(String entryId)` | Marks an unlocked entry as "seen" (removes the notification dot). |
| `setCustomName(String entryId, String name)` | Sets a custom name for an entry for this player. |
| `setCustomDescription(String entryId, String desc)` | Sets a custom description for an entry for this player. |
| `setJournalTitle(String title)` | Changes the title of the player's journal. |
| `isUnlocked(String entryId)` | Check if an entry (or variant like `minecraft:cow#variant`) is unlocked. |

#### ServerFieldGuideManager
Accessible via `FieldGuide.getManager()`.

| Method | Description |
| :--- | :--- |
| `getAllEntryIds()` | Returns a `Set<ResourceLocation>` of every valid entry in the guide. |
| `hasEntry(ResourceLocation id)` | Returns `true` if the ID is a valid entry defined in a category. |
| `getCategoryForEntryId(ResourceLocation id)` | Returns the `ResourceLocation` of the category containing the entry. |
| `isKillToUnlock(ResourceLocation id)` | Returns `true` if the entry is tagged as `#fieldguide:kill_to_unlock`. |
